# Mamba 1.6.0

- Redesigned desktop navigation, Settings, game details and download release browsing.
- Larger centered game artwork, integrated launch actions and accessible installation management.
- A unified Recently Played list that grows with the window and temporarily highlights the newest unplayed installation.
- Library grids capped at five columns, with uncropped artwork and permanently available controls.
- Theme-aware branding, real regular/bold interface fonts, improved Play contrast and restrained interaction motion.
- Shared artwork caching and reduced ambient glow outside Home.
- AppImage startup fix for Windows-only helper registration.
- Expanded direct-host download handling and regression coverage.

Validation: 214 automated tests pass, formatting passes, and Electron renderer checks cover keyboard/mouse navigation, themes, artwork, installation disclosures, and responsive layouts. Renderer DPI checks were performed at 125% and 150%; physical Windows display settings were not changed.
